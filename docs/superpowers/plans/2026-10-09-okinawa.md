# Okinawa Family Trip Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement these tasks in this session. Steps use checkbox syntax for tracking.

**Goal:** Deliver a usable local Korean Okinawa planner with Google Maps and a prepared Vercel/Supabase sharing path.

**Architecture:** Next.js UI calls authenticated JSON route handlers. Shared data is a versioned Supabase document; local preview uses a JSON-file adapter. The map uses established Google Maps and Leaflet libraries.

**Tech Stack:** TypeScript, Next.js, React, lucide-react, Zod, jose, Supabase JS, react-google-maps, Leaflet, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-09-okinawa-design.md`

## Global Constraints
- Korean, mobile-friendly UI; Vercel is the requested hosting provider.
- Family members use one shared password and may all edit.
- Production never uses filesystem persistence.
- No user data or secrets in logs.
- No landing page or feature marketing.
- Dates and traveler counts are unconfirmed and remain empty.

## Review Focus
- Reducing the number of days must not silently remove scheduled activities.
- Duplicate or dangling place references must be rejected before saving.
- Simultaneous writes must not overwrite a family member's newer changes.
- Google authentication failures must leave a working fallback and external directions.
- Network failures must preserve unsaved editor values and show failed save status.
